# Mobile editorial typefaces

Self-hosted, unmodified variable TrueType files downloaded from the Google Fonts
OFL distribution on 2026-11-12. No Google Fonts request is made by the app.

| Family | Public source folder | Included files / licence |
|---|---|---|
| Newsreader | https://github.com/google/fonts/tree/main/ofl/newsreader | `Newsreader[opsz,wght].ttf`, `Newsreader-Italic[opsz,wght].ttf`, `newsreader-OFL.txt` |
| Hanken Grotesk | https://github.com/google/fonts/tree/main/ofl/hankengrotesk | `HankenGrotesk[wght].ttf`, `hankengrotesk-OFL.txt` |
| Geist | https://github.com/google/fonts/tree/main/ofl/geist | `Geist[wght].ttf`, `geist-OFL.txt` |
| JetBrains Mono | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono | `JetBrainsMono[wght].ttf`, `jetbrainsmono-OFL.txt` |

Each accompanying SIL Open Font License 1.1 is preserved verbatim. Font-face aliases
and usage are scoped to the mobile presentation. No reference screenshot, export
photography or fictional listing content is included in these assets.
